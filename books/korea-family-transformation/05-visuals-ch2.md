### [ch2-img02] 위치: 2.6절 말미, "[FIGURE 4 — GENDERED ECONOMY OF INDUSTRIALIZATION]" 표시 직후 (본문 99행, 챕터 마지막)

- 종류: 흐름도 (Gendered economy diagram, half page) — **AI 생성 적합 (개념적 다이어그램, 단 텍스트는 최소화 권장)**
- 내용: 공장 임금(factory wages) → 가계 송금/이전(household transfers) → 무급 돌봄노동(unpaid care) → 교육 투자(education investment) → 도시 주거(urban housing)로 이어지는 순환적 흐름. 이 챕터의 핵심 주장 — "산업화는 여성의 임금노동과 무급노동이라는 보이지 않는 보조금 위에서 이뤄졌다" — 을 시각화.

- 제작 방식 권장: 텍스트 정확성 리스크를 줄이기 위해 **2단계 접근**을 권장한다.
  1) 아래 프롬프트로 AI가 "라벨 없는" 개념적 흐름 일러스트를 생성 (5개의 시각적 매듭/장면만 표현: 공장 → 집으로 건네지는 돈 → 아이를 돌보는 손 → 책·학용품 → 아파트 건물).
  2) Production 단계에서 Canva 등으로 5개의 짧은 라벨과 화살표를 오버레이해서 정확한 텍스트를 얹는다.
  - 만약 한 번에 텍스트까지 포함해서 생성하고 싶다면, 라벨을 최대 5개·각 2단어 이내로 극도로 짧게 유지하고 결과물의 글자가 깨지지 않았는지 반드시 확인할 것.

- 생성 프롬프트 (텍스트 없는 버전, 권장):
  > "A half-page conceptual flow diagram illustrating an economic cycle with five connected visual nodes arranged in a circular or left-to-right flow: (1) a stylized textile factory building with light streaming from windows, (2) a hand passing money/an envelope toward a modest home, (3) a mother's hands cradling a child representing unpaid care work, (4) an open book and pencil representing education investment, (5) a high-rise apartment building silhouette representing urban housing. Connect the five nodes with bold directional arrows in a clear circular flow. Bold, vivid editorial infographic style like a premium travel magazine or National Geographic graphic — NOT a flat pastel minimalist AI-assistant style, NOT a gaudy neon/gradient AI-generated look. Use confident, saturated accent colors (deep indigo, warm ochre, brick red, muted teal) with strong contrast against a warm off-white background, not muted pastels. Strong typographic hierarchy is not needed here since this version has NO text or numbers anywhere in the image — leave clean negative space near each node for labels to be added later in layout software. Clear single focal point per node, purposeful use of color blocks and flat illustration to create visual interest — avoid excessive empty white space and avoid decorative icons unrelated to the five described elements. No gradients, no neon glow, no 3D bevels, no photorealistic human faces. 4:3 aspect ratio, half-page composition."

- 생성 프롬프트 (텍스트 포함 대안, 라벨 5개까지만 허용):
  > "Same composition and style as above, but add five short printed labels directly beneath each node, in a single bold sans-serif typeface, each label no more than two words: 'Factory Wages', 'Household Transfers', 'Unpaid Care', 'Education', 'Urban Housing'. Keep all text large, high-contrast, and minimal — verify no misspelled or garbled characters before use; if any label renders incorrectly, regenerate or remove text and add it manually in layout software instead."
